# 广告调整页

入口：顶部「广告调整」，路由 `/adjustments`。此页面只读，不直接修改广告预算或状态。

- 上海时区当天经营数据；前天、昨天仅作为 D0 ROAS 对照。
- 产品、渠道决定数据范围。搜索系列名称/ID、账户、优化师、国家按 AND 在原始明细上筛选后重新汇总。
- 系列 → 广告组 → 素材按稳定 ID 及父级隔离。收入使用各层实际返回值，不将系列收入分配给下级。
- 达标根据指标库对应产品/渠道的 D0 标准判断；缺数、过期或未配置标准只进入「全部」。
- 四小时持久缓存，切换账户/人员/国家不重新请求 Doris。页面打开时每四小时自动读取，跨上海午夜自动切换当天；关闭页面不启动独立后台定时任务。手动刷新更新三天数据。
- 缓存复用现有容量上限与完整性分片查询，失败保留旧数据并标记；不将缺数补成零。
- 总览收入汇总已返回值，单个系列未返回收入仍显示 `—`。变现 eCPM 没有系列级归因时显示 `—`，不冒用买量 CPM。

验证：单元测试覆盖 AND 筛选、重新汇总、层级隔离、三日对应、四小时缓存边界、强制刷新和缺数保护。真实 Doris 的三日 WingsLite/Facebook 数据在隔离测试库验证搜索与系列/广告组/素材展开，不写生产投放数据。
