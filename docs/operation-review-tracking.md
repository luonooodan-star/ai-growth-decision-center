# 广告调整实操复盘

- 成功且有 API 回读结果的修改自动归类为增量、减量、关停、开启。预算百分比为 `(新预算 / 原预算 - 1) × 100`；原值为零不虚构百分比。失败、待执行、结果不确定不计为已执行措施，原任务审计仍保留。
- 每次成功修改保存不可覆盖的操作锚点；提交前已保存的 Doris 快照、策略版本及当时已审核知识冻结在任务内。不使用后来回填的数据冒充操作前快照。
- 每个对象以最新调整时间重新计时，每 3 小时记录系列累计数据。服务每 5 分钟检查到期对象，按个人 Doris Key、产品串行触发抓取，复用并发门控与完整性校验；原有小时抓取也可完成到期记录。服务必须在线；网络、权限、并发抓取可能延迟。停机后只补当前时点，不补造遗漏的历史时点。
- 关停对象停止其追踪；广告组关停停止已知该组广告，系列关停停止整个系列。再次开启建立新锚点。仅依赖本系统确认执行的操作，不声称识别外部 Meta 后台发生的变化。状态未知不假定正在投放。
- 快照按账户+系列归属，广告/广告组措施不代表已取得对象粒度 D0。快照显示真实数据日、抓取时间、完整性信息，不将累计值当三小时增量。
- 分类先在服务端过滤再分页。展开操作可查看同账户同系列全部操作与最近 2000 条快照；趋势展示最近 100 点，界面会声明截断，更早记录不删除。
- 每个产品的 Skill 页提供操作证据入口。每半小时检查上一完整自然周证据，按产品和优化师生成去重的 Codex 待处理报告。报告包括前后数据、三小时观察、当时的建议/策略及实操分歧。证据超过上限显式标记截断。
- Codex 仍通过现有 `claim-weekly / submit-weekly / fail-weekly` 执行器分析；本次新增服务器证据入队，不替代或启动桌面执行器。执行器离线时显示等待 Codex，不伪造已完成。
- 新一周操作冻结当时已审核策略；周报告要求对照适用条件、实际方向、预算比例及后续效果，区分偏离、不适用、证据不足和改进空间。自然语言策略的适用性由 Codex 复盘，不把任意不同操作直接判为错误。候选仍需审核后入库，不自动发布规则或改广告。
- 凭据、原始操作与快照保持个人隔离，审核知识及周报告沿用团队共享。历史记录保留，不启动旧 MCP 操作采集。
