# 广告系列决策台实施计划

## 目标与验收

产品页优先回答：哪些系列值得投入、哪些需要减量、具体执行什么、执行后是否改善。
一个 Campaign 一张卡，正常系列默认折叠。异常指标保留为证据；产品页不再显示重复的旧异常、观察、建议及实验模块，已有数据库记录和实验库保留。
不以减少提示或增加 AI 长文作为成功标准；试运行记录人工处理耗时、建议执行率和成熟数据改善情况。

## 本次交付

1. 每次 Doris 抓取保存全部系列逐日快照（包含正常系列），按产品、账户、Campaign 隔离。
   归并消耗和分母后计算比率；D0 只来自同日成熟 cohort，不把当日收入 ROAS 当 D0。
   国家作为覆盖范围显示，当前 cohort 无国家粒度时不提供虚假的国家级 D0。
2. 五类判断：加量、减量、调整广告、观察、正常。前一天与连续多天趋势并列；
   过期、缺数据、低样本或未设置标准时不输出可执行预算指令。
   产品可配置样本门槛、持续天数、单次幅度、复查时间；初值是试运行参数，不是已验证最优值。
3. Codex 按整个系列领取上下文，包括可取得的指标、广告组/广告、趋势和最近措施。
   相同数据及策略版本复用已有任务；模型结果不能绕过样本门槛和对象校验。
4. 接受建议生成待执行单，登记实际预算层级、原预算、目标预算或广告动作。
   人工确认已执行后才开始实验；接受、拒绝、观察、执行均留活动记录。
   每小时抓取沿用实验监控，展现实际执行时刻、执行前最近可用快照、后续快照及复查条件。
5. 部署沿用公司 Mac / GitHub；SQLite 加表兼容升级，无须妙搭授权，不改上传工具。

## 边界

- 未连接 Facebook 写接口，所有实际投放变更由人工完成；页面不声称自动执行。
- 买量 CPM 在新工作台明确标注；旧 ecpm 字段保留以兼容历史数据，不能解释成产品变现 ECPM。
- 日累计数据每小时刷新，不等于小时增量；成熟日改善与执行后的实时因果证据分开解释。
- 优先保留完整系列粒度。无法确认账户归属或完整性时，展示缺口并阻止预算动作。
- 首版预算单只支持 Campaign 控制的日预算。广告组预算、未覆盖全部国家的系列不能套用整系列预算建议。

## 后续迭代与试运行

1. 首版部署后补齐近 7 天，人工校准产品达标线和样本参数；每天核对优先级最高的系列，记录处理耗时与不接受原因。
2. 有独立广告组成熟回报及预算配置后，再增加广告组预算单、版位/人群排除单，避免系列效果被错误分配到局部。
3. 按措施和广告组复盘：同时比较目标指标、安装规模及同期其他变更；区分前后相关性与对照实验。结论经人工确认后进入规则候选，不自动放宽产品达标线。
4. 验收关注单系列判断耗时、建议实际执行率、复查完成率和成熟数据改善率。前后耗时及效果须真实试运行后测量，不预先宣称已经提效。

## 验证

覆盖：优秀系列进入加量候选、持续不达标进入减量、缺数/过期/样本不足保护、
聚合不重复计量、跨账户隔离、同版本任务去重、采纳不启动监控、执行幂等、拒绝留档。
完成类型检查、相关单元与接口测试、公司 Mac 构建后推送 GitHub。

首版验证记录：22 项单元测试通过，前后端类型检查、公司 Mac 构建通过；
隔离数据库验证接口鉴权、任务去重、接受和登记执行流程、执行基线，以及桌面/手机布局。
尚未在公司服务器升级验证，也未以真实投放结果证明决策效果提升。

## 系列规则与一键分析迭代

- 决策台增加“一键分析”：分析当前筛选下的系列，每批最多 20 个系列合成一个任务，结果分别回写。
  相同数据及规则版本已排队或完成的任务跳过；失败任务允许重试。提交成功不等于分析完成，仍需分析 Worker 领取。
- “系列判断规则”提供加量、减量、调整广告、观察、正常五类新增入口，按产品独立保存。
  每条可设置指标上下界、较前一天变化百分比、连续天数、具体措施、匹配优先级和“异常优先处理”。
  多条件同时满足；上下区间可对同一指标添加 ≥ 下界与 ≤ 上界两条条件。
  多条命中按匹配优先级降序、同级按规则 ID 排序；未命中沿用内置判断。
- 新规则默认停用，填写完整后启用并点击“保存规则并重新判断”。百分比指标输入 70 表示 70%，环比 -20 表示下降 20%。
  保存采用版本冲突检查，修改及删除留档，不改变历史执行单。
- 异常优先处理独立于匹配优先级：前者控制卡片排序和筛选，后者决定多条规则的命中顺序。
  数据缺失、过期、低样本或已有执行中的措施仍优先进入观察；自定义加量规则不能绕过达标保护和预算幅度上限。
  不把缺失指标或缺少前一天数据当成 0，不根据规则自动修改 Facebook 投放。
- 本轮验证：28 项测试通过，覆盖规则校验、跨产品隔离、变更留档、版本冲突、规则优先级、环比连续性、批量去重及入队失败重试；
  隔离数据库浏览器验证一键分析、规则新增/启用/保存/删除、排序、执行登记与桌面/手机布局。
